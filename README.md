# Exploratory Data Analysis (EDA)

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) using Python. The main objective is to explore a dataset, understand its characteristics, identify patterns, and discover meaningful insights.

## What I Worked On

Explored the cleaned dataset and generated descriptive statistics to understand the data. Analyzed sales trends across different cities, categories, products, and payment methods. Also examined monthly sales patterns and identified potential outliers using statistical techniques.

## Key Takeaway

Learned how Exploratory Data Analysis helps identify hidden patterns, understand relationships within data, and generate meaningful insights for better decision-making.
